# Purti (ფურთი) — project notes

A web version of ფურთი, the Georgian card game of elevens, built for fun to play with a friend.

## Files
- `index.html` — the whole app (HTML + CSS + JS, no build step).
- `database.rules.json` — Firebase Realtime Database rules; paste into the console (Realtime Database → Rules).
- `README.md` — description, one-time Firebase setup, and the rules as implemented.

## How it works
- Modes: online (4-letter room code), 2 or 4 players, everyone for themselves; practice is 1 vs the computer only. 4-player games need 4 people (the user chose no computer seats online).
- Online play uses Firebase Realtime Database (compat SDK v10 from gstatic) with anonymous auth. `FIREBASE_CONFIG` near the top of the script must be filled in; while it is `null`, online play shows "not set up".
- Data: `rooms/<CODE>/{created, size, target, seats, players, state, online, closed}` (`target` 11|21, set by the creator). `created` is seat 0 and sets `size` (2|4); joiners claim `seats/1..3` in order (RTDB rules have no `numChildren`, so explicit seats cap the room). Seat order is playing order. A name already used in the room is refused. `state` is the whole game as a JSON string (strings avoid Firebase dropping empty arrays). Moves are shown locally at once and saved with a transaction that only accepts a higher `seq`, so the first write wins and everyone follows the server copy. `online/<uid>` is presence: `true` while connected, and the server time they left (set by `onDisconnect` or on leaving) once gone.
- Leaving (user's choice, 2026-11-14): a player who leaves (←, closed tab, lost connection, Menu) can rejoin for 2 minutes (`GONE_MS`); the home Rejoin button counts down from `session.at` (refreshed every second while in the room) and then disappears. Once a player's leave time is 2 minutes old, any player still in the room writes `closed` (server timestamp); everyone is moved home with a notice, and the rules refuse seats, names and moves in a closed room. Joining/rejoining also refuses a room that is closed or has a player gone over 2 minutes. A phone that sleeps or loses its connection for 2+ minutes ends the game too.
- Running totals count MATCHES (user's choice): `matches/<group>/<matchId> = {w, t}`; the older per-round `results/<group>/<gameId>` is no longer read. Formerly: `results/<group>/<gameId> = {w, t}`, where `<group>` is all players' lowercase names, sorted (`groupKey`), so each pair or foursome has its own record; `w` is "" for a draw. Every client writes the same entry in a transaction; only the first is kept, so each game counts once.
- Players are anonymous Firebase users; the uid is kept per browser, so rejoining works on the same browser/device, not from a different one. `?guest`, `?guest=2`, `?guest=3` give a tab its own uid and storage for testing several seats in one browser.
- Languages: English, Georgian, French (`T.en` / `T.ka` / `T.fr`; `LANGS` sets the switcher: three buttons EN · ქარ · FR, tap one to pick it). French is the default (user's choice) until a player picks another. Name, language and the last room (`session`, for the Rejoin button) are kept in localStorage. Rejoin is forgotten after Menu on the result screen, the × next to it, or 2 minutes; leaving mid-round with ← keeps it for those 2 minutes. A name is required for online play.
- Rules: 4 cards each, 4 on the table; number cards (Ace = 1) take table number cards that add to 11 with them; K takes K, Q takes Q; the Jack takes everything except Q and K; leftovers go to the last capturer. Scoring (`scoreRound`): most cards 2, 2♣ 1, 10♦ 1, most clubs 1; a shared lead in cards or clubs earns nobody those points; most points wins, a shared top score is a draw (only possible with 4). No ★ sweeps (the user removed them). No capture hints (the user wants players to find the 11s themselves). No in-app "How to play" (the user removed the home link, the in-game ? button and the rules text, 2026-11-14); README keeps the rules. Players CHOOSE the capture (`captureOptions`, `validTake`): tap table cards, then the hand card again; one group per turn; nothing picked = put the card down; an invalid pick is refused with a message. The Jack still takes automatically.
- Matches: `newRound(mode, players, prev, target)` continues `prev`'s match unless `prev.mover`; state has `match` (id), `target`, `tot` (match points), `mover`, `mw`. Match ends when someone reaches the target and is alone on top; a tie at the top plays another round.
- Game state is versioned (`STATE_V`, now 3). Bump it when the state shape changes; an older saved game in a room is replaced by a fresh deal.
